Quiz Bíblico

Crie uma sala, compartilhe o PIN e jogue com seus amigos. Responda rápido para disputar o bônus e use ferramentas com estratégia.

Como funciona
  • Um jogador cria a sala e vira host automaticamente.
  • Outros entram com PIN + nome (até 4).
  • O host clica em Iniciar para começar.
  • Cada rodada tem tempo por nível (Fácil/Médio/Apocalipse).
